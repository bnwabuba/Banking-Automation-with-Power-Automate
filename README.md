# Banking Automation with Power Automate  

## Project Overview  
This project automates **loan repayment reminders and customer birthday messages** for a bank using **Microsoft Power Automate**. The automation reduces **manual workload, improves efficiency, and cuts operational costs**.  

## Problem Statement  
- Manual reminders were time-consuming and prone to human error.  
- Some customers missed repayment deadlines, leading to increased loan defaults.  
- Sending birthday messages manually was inconsistent and inefficient.  

## Solution Using Power Automate  
I created two automated workflows:  
1. **Loan Repayment Reminders** – Fetches due loan data and automatically sends email reminders.  
2. **Birthday Message Automation** – Extracts customer birthdays and sends personalized messages via Email.  

## Tools & Technologies Used  
- **Microsoft Power Automate** – For automation workflows  
- **Microsoft Outlook** – For email automation  
- **SQL Database** – To fetch customer data  
- **Power BI** – For performance tracking  

## Impact  
✔ **30% reduction in overdue loans** within 3 months.  
✔ **100% automation of customer birthday messages**, improving engagement.  
✔ **Significant cost savings** due to reduced manual effort.  
✔ **Enhanced operational efficiency**, freeing up staff for higher-value tasks.  

## Future Improvements  
- Integrate **WhatsApp chatbots** for interactive loan reminders.  
- Use **AI for sentiment analysis** on customer responses.  
- Automate feedback collection to improve services.
